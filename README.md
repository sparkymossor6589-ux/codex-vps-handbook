# Codex VPS 实战手册

**基于现有开源工具，记录用 Codex 完成 VPS 搭建、维护与应用去广告的过程。**

从一台个人 VPS 开始，记录怎样借助 Codex 完成服务器部署、多设备接入、在线配置更新、日常故障排查和应用广告拦截。提供分步教程、可复用提示词、配置示例，以及从实际项目整理的维护源码。

适合希望借助 AI 管理个人服务器、又希望知道每一步做了什么的人。

连接核心、客户端以及应用规则和脚本由相应上游作者开发。本项目整理使用者需求、部署适配、维护程序与排错教程，Codex 辅助编写和迭代。详见[项目贡献](CONTRIBUTIONS.md)、[第三方署名](THIRD_PARTY_NOTICES.md)和[逐项许可检查](docs/13-license-review.md)。

## 你能从这里获得什么

- **从需求到部署**：把预算、设备和使用场景交代给 Codex，再完成服务器和客户端的基本连接。
- **按实际业务分流**：国内应用与局域网直连，指定服务通过自己的节点访问，并检查客户端实际命中。
- **减少重复操作**：将节点订阅、分流配置和应用模块分别管理，通过私人 HTTPS 入口更新。
- **解决使用中的问题**：保留安卓入口 404、蜂窝音乐加载和 Steam 下载分流等排查案例。
- **逐步加入去广告**：独立管理应用模块、脚本依赖和本机证书，记录知乎开屏问题的处理过程。
- **持续维护**：为每次变更保留来源、检查结果和回退办法。

## 项目是怎样一步步形成的

| 阶段 | 当时的需求 | 形成的做法 |
|---|---|---|
| 选型与搭建 | 有一台自己可管理的服务器 | 明确预算、地区、计费和访问方式，再部署连接服务 |
| Mac 分流 | 保持常用国内应用正常使用 | 建立明确的规则顺序，抽查真实业务域名 |
| 多设备接入 | 手机与安卓设备便于导入 | 区分节点订阅、分流配置和接入网页 |
| 在线维护 | 更新后少传文件、少重复导入 | 保持稳定地址，保留版本化文件与回退材料 |
| 日常修补 | 音乐加载慢、Steam 下载路径不合适 | 只调整有依据的目标规则，分别验证发布与实际使用 |
| 应用去广告 | 处理常用中文应用中的广告 | 独立模块、固定依赖、设备独立证书与逐应用检查 |
| 知乎专项 | 模块开启后仍有开屏广告 | 增加定向实验，再结合手机使用反馈确认效果 |

过程中的失败、状态变化和待测内容见[项目经过](docs/10-project-story.md)。

## 开始使用

1. 阅读[准备与协作方法](docs/01-start-with-codex.md)，把自己的设备、目标和约束写清楚。
2. 按[服务器搭建](docs/02-server-setup.md)完成基础连接，再加入[分流与客户端](docs/03-routing-and-clients.md)。
3. 需要减少日常操作时，再阅读[在线更新与流量估算](docs/04-online-updates-and-traffic.md)。
4. 基础连接稳定后，根据需要加入[应用去广告](docs/06-adblocking.md)。

已经有服务器，可以直接从分流或故障案例开始。配置中的 `REPLACE_WITH_...`、示例域名和测试令牌都需要替换；填过真实参数的文件留在自己的私人目录。

## 环境与验证范围

实际项目采用 AWS Lightsail 东京实例、Ubuntu、Xray 的 VLESS + REALITY + Vision，以及 Mac / iPhone 上的 Shadowrocket；安卓接入基于 Mihomo 格式。它们用于说明真实过程，其他地区、系统和客户端需要重新确认参数。

| 项目 | 已有证据 | 尚未覆盖 |
|---|---|---|
| Mac 基础连接与分流 | 客户端检查、业务域名抽样和基础联网记录 | 所有应用功能、长期稳定性与睡眠恢复 |
| iPhone 基础连接 | 用户确认 Wi-Fi、蜂窝下 ChatGPT 文字回复正常 | 上传、实时语音和后台更新实际触发 |
| 安卓接入 | 入口、配置交付、内核解析与本地检查 | 安卓真机导入与实际使用 |
| Steam 分流 | 规则命中、网页与更新清单访问 | 真实游戏长下载及持续速率 |
| iPhone B 站 | r8 对应广告位消失曾获用户确认；r12 后首页 / 播放异常 | r13 兼容性修补后手机恢复和广告效果待确认 |
| iPhone 知乎广告 | 冷启动曾获无开屏反馈；后续切回广告仍在，r13 继续补漏 | 未确认完全解决；不扩展为全版本或其他应用效果 |
| 安卓开屏跳过 | 已整理 GKD 官方入口与第三方订阅路线 | 尚未完成安卓真机验收 |
| Mac 去广告链路 | 本机证书、接口拦截对照与基础联网检查 | 14 款应用逐项使用效果 |

这些是项目历史记录的范围；公开源码只在本地进行相应检查，不代表已在读者的新服务器部署完成。详见[验证状态](docs/09-validation.md)。

## 与 Codex 协作的方法

把目标、上下文、必须保留的行为和检查方法一次说清。每次处理一个可以验证的目标，例如“修复音乐蜂窝加载，同时保留现有节点和其他分流”，然后让 Codex 给出改动、证据和回退办法。

本仓库的提示词根据实际过程重新整理，均标为**可复用示例**，不作为历史聊天逐字引用。[OpenAI 官方提示词文档](https://learn.chatgpt.com/docs/prompting#prompting-codex)也采用明确目标、相关上下文、约束与验证方法的组织方式。
