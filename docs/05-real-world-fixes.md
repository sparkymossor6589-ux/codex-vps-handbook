## 视频分流 v5 · 2026-10-23

最终只保留 Dailymotion 四条补丁；示例的 `VPS` 替换成自己的策略组，精确媒体规则放在后缀前：

```text
DOMAIN,vod3.cf.dmcdn.net,DIRECT
DOMAIN-SUFFIX,dailymotion.com,VPS
DOMAIN-SUFFIX,dmcdn.net,VPS
DOMAIN-SUFFIX,dai.ly,VPS
```

两个公开样本的播放清单和高画质媒体小段在 Mac 通过直连 / 代理对照，再经现有客户端复核。直连测试绑定物理接口并检查作用域路由，不能只凭关闭 HTTP 代理选项判断出口。

仅覆盖已测媒体主机；网页、API、未验证媒体保持原策略，不整体直连公共 CDN。Vimeo / Twitch 未通过直连，TED 试验条目已撤回，YouTube / Reddit 未完成匿名媒体对照。

原 405 条规则保持，新增后共 409 条；在线地址和配置名不变。手机需要更新**分流配置**并另行验证，完整观看与长期稳定仍待测。回退只移除这四条补丁，不覆盖后来维护。
