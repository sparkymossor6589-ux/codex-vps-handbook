# 本轮来源与许可证检查

以下记录针对首轮公开整理的本地来源与许可复核。逐项核对了 **21 个仓库、1 份 Gist、14 款应用入口、22 项历史运行来源**，并检查预览中代码、样例与文字的归属。

## 已作的修改

1. 首页增加本项目与上游的贡献边界，取消“仓库内容统一原创 / 统一 MIT”的概括。
2. 新增 THIRD_PARTY_NOTICES.md、LICENSE_SCOPE.md、CONTRIBUTIONS.md 与逐文件来源清单。
3. 完整保留 15 份上游许可证和 1 份实际存在的 NOTICE，按 commit 与 Git blob 校验，未改写原作者信息。
4. 为 14 款应用补充作者、仓库、许可观察与分发决策；13 个仓库源文件与原记录哈希一致，另 1 个发布资源与本地原件哈希一致。
5. 补充 21 份 JavaScript 和 1 份规则文件的来源与作者；保留什么值得买脚本的双作者署名，以及微博相关来源。
6. Xray 服务端样例增加单独署名与改动说明，按 CC BY-SA 4.0 处理。MIT 不覆盖上游许可文本或该样例。
7. 未明许可、额外声明和混合来源分别列项；没有将“公开可见”改写成“自由再分发”。

## 没有因此获得的结论

原私有去广告运行包及其所有内嵌库没有取得全面再分发核准。它们继续留在原项目，不进入公开预览。AI 辅助代码的本地生成记录，也不是完成全网逐行来源证明。

Mihomo 的核对按实际网络内核 v1.19.32，避免套用同名 Python SDK 的 MIT 文本；这只是明确本次检索对象，不据此推断仓库发生了什么变化。

公开目录与对应交付材料已随结果更新。本轮只写公开副本及本地审阅材料，不写原项目和运行设备。核对期间发现原项目两份状态说明新增了知乎回前台仍有广告的记录，已保留原更新并同步收窄公开表述。
