# 应用去广告

节点、主分流与去广告模块分别管理，便于定位和停用。首批整合 14 款应用，来源见 [应用索引](../data/upstream-apps.json)；整合不等于逐项验收。

## 使用步骤

1. 阅读上游规则、依赖、附带功能、客户端要求和许可；不要同时启用总模块与同应用独立模块。
2. 需要 HTTPS 解密时，在**各自设备**生成、安装并信任自己的 CA，再启用模块。[Apple 证书信任说明](https://support.apple.com/en-us/102390)
3. 先测一个应用，分别观察冷启动 / 切回前台、Wi-Fi / 蜂窝，以及搜索、播放、评论等正常功能。
4. 查看实际命中、脚本处理和回包。设置开启、空数组或接口 200 都不能单独证明广告已消失。
5. 出现正常功能异常时，先停用模块或恢复自己验证可用的版本；不要同时重建节点和证书。

[模块示例](../examples/adblock-module.srmodule.example)仅展示格式，不含可用第三方规则、MITM 主机或共享证书。第三方作者与许可见 [署名总表](../THIRD_PARTY_NOTICES.md)。
