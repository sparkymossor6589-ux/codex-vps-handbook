# 应用去广告

节点、主分流和应用模块分开维护。当前模块 r39 的改动与问题见 [排查记录](14-adblock-followup.md)；测试状态统一放在 [验证表](09-validation.md)。

## 配置与测试

1. 阅读上游规则、依赖、附带功能和许可。总模块与同应用的独立模块不要重复启用。
2. 需要 HTTPS 解密时，在各自设备生成、安装并信任自己的 CA，再启用对应模块。[Apple 证书说明](https://support.apple.com/en-us/102390)
3. 每次先测一个应用。检查冷启动、切回前台、Wi-Fi / 蜂窝，也检查首页、阅读、评论、搜索和播放。
4. 查看实际命中和处理结果，再确认应用展示。出现误拦时，先停用本次处理或回退，不同时更换节点与证书。

首批 14 款应用的来源保留在 [应用索引](../data/upstream-apps.json)；后续还尝试了淘宝 / 闪购和 QQ 的定向规则，效果仍需分别验收。

[模块示例](../examples/adblock-module.srmodule.example)只演示格式。需要的实际规则和脚本请按 [上游来源与许可](../THIRD_PARTY_NOTICES.md)自行审阅。安卓看 [GKD](15-android-gkd.md)。
