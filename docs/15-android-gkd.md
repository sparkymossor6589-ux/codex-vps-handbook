# 安卓开屏：使用 GKD 自动点击跳过

这是安卓适配路线，**本项目尚未完成安卓真机验收**。GKD 基于无障碍与订阅规则执行屏幕点击；它与现有 Clash / Mihomo 的网络分流分别工作，不是将 iPhone 小火箭模块导入安卓。

## 安装与设置

1. 从 [GKD 官方指引](https://gkd.li/guide/)选择当前正式发布渠道，在自己的手机安装并打开。安装包和界面可能随版本变化，本仓库不提供 APK。
2. 按指引理解并授权无障碍服务。该权限允许应用读取界面并执行操作；只在确认来源和用途后开启。系统若提示受限，按官方说明核对安装渠道和具体设置，不照搬其他机型截图。
3. 在订阅页面选择规则。本项目研究过 [Lin-arm/GKD_subscription](https://github.com/Lin-arm/GKD_subscription)，它是第三方社区规则，不是 GKD 官方内置规则。请从其 README 获取当前订阅地址并阅读规则范围；本仓库不镜像规则。
4. 初次只启用目标应用的开屏规则。从后台退出再打开，观察是否自动点击“跳过”，并检查搜索、回答、评论等正常功能。Wi-Fi 与蜂窝分别记录。

本方案不要求为 GKD 安装 HTTPS 解密证书，也不要求重新导入现有节点或分流。广告可能先出现再被跳过；没有可匹配按钮、规则变化或缓存状态不同，效果也可能变化。

## 失效、误点与回退

短时有效、随后停止时，先核对无障碍服务和系统后台限制，再参考 [GKD 常见问题](https://gkd.li/guide/faq)。避免同时启用多份重复订阅和大量无关功能。

发生误点时，停用对应规则；需要完全停止点击时关闭 GKD 无障碍服务。这个回退与 Clash 的节点、VPN 和分流无关。
