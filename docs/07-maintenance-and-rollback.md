# 维护与回退

日常核对：服务状态、磁盘 / 内存、HTTPS 证书续期、客户端使用版本、代表性规则命中、常用业务与实际账单。每月另查赠金余额、到期日及额外资源费用；在 Free plan 结束前决定是否继续使用并升级，在赠金到期前决定自费续用或备份后删除计费资源。[费用与期限](01-start-with-codex.md)

每次修改保留一条记录：

```text
日期 / 环境 / 目标：
执行前版本与备份：
改动及来源：
检查结果与设备待测项：
回退方法：
```

## 回退顺序

1. 区分节点、分流、入口与应用模块的问题。
2. 先停用本次模块或撤销具体补丁，再刷新客户端复测。
3. 需要恢复文件时，先保存当前状态。运行中的客户端不要直接覆盖数据库。
4. 节点凭据、流量累计和设备证书不随普通规则补丁一起重置。

关闭网页入口只阻止后续获取，已导入节点的撤销还需处理服务端凭据。需要独立撤销时使用独立授权，不能把多个入口名称当作隔离证明。

整理文件时保留当前交付、来源、回退和验收原件，过时材料移到可恢复位置。公开前检查文件和提交历史，见 [SECURITY.md](../SECURITY.md)。
