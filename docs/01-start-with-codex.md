# 准备与 Codex 协作

告诉 Codex：设备与版本、Wi-Fi / 蜂窝环境、常用业务、预算、本次目标，以及必须保留的现有配置。

```text
请先检查已有环境和备份。
本次目标：[一个具体问题]。
约束：[不能改变的节点、分流或其他行为]。
完成后给出改动、检查证据、设备待测项和回退方法。
真实凭据只保存在本地私人文件。
```

每轮只处理一个能验证的目标。你负责账户操作和真实设备使用确认；Codex 检查文件、修改程序和整理结果。记录日期、版本、来源、测试与回退点。

参考 [OpenAI Codex 提示词文档](https://learn.chatgpt.com/docs/prompting#prompting-codex)。更多模板见 [提示词](08-prompts.md)。
