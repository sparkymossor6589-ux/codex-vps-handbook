# Codex 提示词

以下是根据项目重写的模板，不是聊天原文。填写方括号，凭据留在自己的私人文件。

## 搭建

```text
设备 / 网络 / 预算：[填写]；目标业务：[填写]。
先比较有日期和来源的方案，再检查系统、架构、端口及已有服务。
保留备份，固定官方版本和校验值；部署后分别核验服务器、客户端和实际业务。
```

## 分流与更新

```text
节点已经能用，本次只调整：[应用及预期出口]。
读取现有规则，保留其他行为；依据实际请求设计精确例外，不整体直连共享 CDN。
发布后回读、刷新对应配置，再检查客户端命中和真实媒体 / 业务。
提供只撤销本次补丁的回退方式。
```

## 去广告排查

```text
设备 / 客户端 / 模块版本：[填写]；现象与复现步骤：[填写]。
先确认请求和响应实际经过哪些处理，不把零日志、空回包或 Mac 样本当作手机成功。
按证据小范围修改，检查广告变化，也检查首页、播放和评论。
原始日志留在私人目录；记录结果、待测项和回退点。
```

## 准备公开版本

```text
另建公开副本，保留原项目。
只保留必要教程、脱敏示例、适合分发的代码和第三方署名许可。
检查真实凭据、私人链接、日志、图片及 Git 历史；先给我看，未经授权不要上传。
```
