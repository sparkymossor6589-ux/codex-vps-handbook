# 去广告后续：r3 → r25

当前私人交付为 **20261023-r25**，Mac 已更新，**手机更新与验收尚未完成**。此前用户反馈部分屏蔽有效，知乎切回全屏广告仍有；空白卡片或空位也不能单独证明误删了普通内容。

| 阶段 | 有用的发现 |
|---|---|
| r3 → r8 | Mac 引擎缺少 TextDecoder；空体 Map Local 与明确 `{}` 不同。修补后 B 站对应广告位曾获有效反馈 |
| r9 → r13 | 精确接口及广告 SDK 入口补漏；r12 手机首页 / 播放出现回归，r13 减少挂接并改为同步过滤 |
| r14 → r16 | 手机脚本已执行并清空部分广告数组，广告仍出现；改用结构化空池 / 请求阶段处理，不能把空回包当展示成功 |
| r18 → r24 | 继续检查素材域名、配置开关和知乎连接接管方式；已有执行证据仍不足以确认手机广告消失 |
| r25 | 修复知乎推荐卡片的未定义变量，提前检查明确广告标签；B 站补齐非空 ad_info / ad_info_v2 / ad_card 标记，保留空对象、普通视频和直播 |

r25 另对 `ossgw.alicdn.com` 候选素材主机做整主机拒绝。尚未对应到问题截图中的具体素材，不是已证实的唯一根因；整主机拒绝可能影响其他内容，需要实际设备复测。

## 能公开复用的内容

[src/bili_feed_safe.js](../src/bili_feed_safe.js) 只保留本地同步 JSON 过滤核心，去除私人诊断封装；不补位联网、不处理正常播放地址，异常或未知响应放行。知乎修改依赖上游脚本，本仓库只记录改动，不重新分发正文。[归属与来源](../CONTRIBUTIONS.md)

最新记录核对了 62 项资源；Mac 的正常推荐、播放地址和一次视频范围读取通过。手机仍需确认首页、播放、冷启动 / 切回广告，状态集中见 [验证表](09-validation.md)。

## 继续排查的顺序

确认设备版本 → 区分请求与响应处理 → 看客户端实际展示 → 检查正常功能。零记录不是缓存或 QUIC 的证明，邻近广告出现的连接也不自动构成因果证据。出现异常时停用新增处理或恢复自己验证可用的版本，不继续盲目叠加规则。
