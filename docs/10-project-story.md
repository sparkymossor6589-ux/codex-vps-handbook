# 为什么搭这套环境

我最初的目标，是利用 AWS 100 美元赠金，搭一台能用一年的个人 VPS，让常用设备接入，并且能自己维护。广告屏蔽是基础连接稳定后逐步加上的功能。

选择 Lightsail 东京的 5 美元 / 月套餐后，一年基础实例费约 60 美元，留出部分赠金余量。这里的一年是预算目标，尚未运行满一年；实际能覆盖多久取决于赠金到期日和额外用量。[预算与条件](01-start-with-codex.md)

## 从搭建到维护

| 阶段 | 做法 | 结果 |
|---|---|---|
| 选型与部署 | 核对赠金和预算，在 Ubuntu 部署固定版本 Xray，检查下载包与配置 | Mac 基础连接可用 |
| 分流与接入 | 保留节点，逐项调整国内应用、音乐和 Steam；建立私人 HTTPS 入口 | iPhone 两种网络下文字对话获确认，其他设备分别验收 |
| 在线维护 | 配置地址保持稳定，资源按版本保存；发布后回读，再更新客户端 | 可定位版本、复测和回退 |
| 视频分流 v5 | 对照真实媒体与实际出口，只保留已测 Dailymotion 媒体主机 | Mac 两个样本通过，未通过的试验撤回 |
| 应用广告 r3 → r39 | 检查脚本、响应、素材和连接路径，同时修复正常功能误拦 | 仍有广告复现；阅读路径与裸 IP 拦截需继续在手机验收 |

Codex 帮我查资料、读代码、修改维护工具和整理记录。方案选择、账户操作和实际使用确认由我完成；底层连接、客户端和大量规则来自各上游项目，见[整理与改动范围](../CONTRIBUTIONS.md)。

这篇攻略按搭建顺序组织，参考代码、故障案例和工具模板供需要的人复用。每次更新保留旧版，先检查常用功能，再逐设备确认新效果。
