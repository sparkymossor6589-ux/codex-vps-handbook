# 项目经过

| 阶段 | 做法 | 结果 |
|---|---|---|
| 选型与部署 | 明确预算、设备和目标业务；在 Lightsail 东京部署固定版本 Xray，核对包和配置 | Mac 基础连接可用 |
| 分流与接入 | 保留节点，逐项调整国内应用、音乐和 Steam；把传文件改为私人 HTTPS 入口 | iPhone 两种网络下文字对话获确认，其他设备分别验收 |
| 在线维护 | 配置地址保持稳定，资源按版本保存；发布后回读，再更新客户端 | 可定位版本、复测和回退 |
| 视频分流 v5 | 对照真实媒体与实际出口，只保留已测 Dailymotion 媒体主机 | Mac 两个样本通过，未通过的试验撤回 |
| 应用广告 r3 → r39 | 检查脚本、响应、素材和连接路径，同时处理正常功能回归 | 仍有广告复现；最新修复阅读路径，裸 IP 拦截处于设备验证阶段 |

Codex 用于读代码、修改维护工具和整理文档；实际效果以各设备使用结果确认。每次保留执行前版本，只改本轮目标，检查正常功能，并准备回退。
